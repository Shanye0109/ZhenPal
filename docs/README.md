# 臻朴采购系统 V2.1.1 使用手册

面向上海臻朴实业有限公司采购协作场景的静态界面展示稿。名称暂定，所有业务记录均为示例。

## 这一版可以做什么

- 查看经营后台、客户门户和后续预留的全部 72 个业务页面入口。
- 使用工作标签页、菜单搜索、列表筛选、翻页和详情弹窗。
- 在客户门户浏览示例商品，调整多收货组购物袋的数量，生成订单预览。
- 阅读完整需求文档，比较五组名称，复制命名意见。
- 切换舒适或紧凑密度、减少动画、默认收起侧栏。
- 导出当前页示例 CSV；导出、检查和恢复当前浏览器的界面偏好。

业务数据不会提交到服务器。真实登录、客户账号、采购提交、开票、物流查询和业务资料备份需后续接入；预览不能用于保存真实订单。

## 直接查看与上传

下载站点包后解压，保留目录结构。推荐上传 GitHub Pages 或使用下方的本地预览方式查看；也可尝试在本地双击 `index.html`，但浏览器可能限制文件页面的脚本与存储。`assets` 文件夹须与 HTML 同时保留。

上传 GitHub 时，上传解压后的文件和文件夹，不只上传 ZIP。把 `index.html`、其他 HTML、`assets` 和 `docs` 放在同一发布目录。旧版的单独 HTML 不足以运行新版，需要一起上传 assets。

如果还未启用 GitHub Pages，在仓库 Settings → Pages → Build and deployment 中选择 Deploy from a branch，选中实际分支和发布目录，保存后访问 Pages 提供的网站地址。已有 Pages 配置时沿用其发布目录。源代码页不是发布后的网页。

如果本地浏览器限制文件页面的脚本或存储，可以使用源码包的本地预览。安装 Node.js 20 或以上，在源码目录执行以下命令：

```bash
npm ci
npm run build
npm run preview
```

浏览器打开终端显示的本地地址即可。普通上传和查看站点包不需要安装 Node.js。

## 常用操作

### 菜单与标签页

侧栏可展开业务分类，也可搜索当前范围的菜单。点击菜单会打开工作标签；关闭当前标签会回到相邻标签。顶部“客户门户”进入独立的客户展示入口，经营后台的下拉选择可以查看后续预留菜单。

手机上点击左上角菜单按钮展开侧栏，点击遮罩或按 Escape 关闭。宽表格可以在表格区域左右滚动。

### 列表与示例导出

搜索支持编号和可见字段，状态标签用于筛选，内容标签用于切换对应展示。零结果会显示提示，清空搜索可恢复。

“导出示例”会先说明行数和字段，确认后下载当前页的 CSV。浏览器负责实际保存位置和同名文件处理，网页不会静默覆盖本机文件。

### 界面偏好

右上角齿轮可以调整密度、减少动画和侧栏。只保存这三项界面偏好，不保存密码、客户、订单或票据。浏览器禁止存储时，当次打开仍可使用，页面会提示保存限制。

### 购物袋

一个购物袋对应一个收货组。加减数量后，整单件数会更新；“生成订单预览”可查看多购物袋合并提交的样式。数量只在本次打开期间保留，刷新后回到演示初始值。

### 名称比较

名称页保留臻伙伴、臻合、臻好办、臻序、臻采的完整比较。可选择第一、第二偏好，填写理由并复制给朋友。选择不会自动保存或上传，关闭页面前请复制需要保留的意见。

## 备份、恢复与回退

### 界面偏好备份

在后台“权限与系统 → 备份与恢复”页面，或客户门户右上角“界面偏好 → 备份界面偏好”，导出当前偏好 JSON。这个文件只包含密度、侧栏和减少动画三个选项。

恢复时先选文件，页面检查大小、格式、版本与允许字段，通过后展示差异。可先下载当前偏好的副本，再点击“确认恢复”。同一次备份页面中，可撤销上一次恢复；离开页面后若要回退，使用恢复前下载的文件。

不支持的文件会给出原因，不修改当前偏好。上限为 16 KiB。此功能不是订单、客户、发票或数据库备份。

### 旧版页面回退

本次另保留原 V2.1 完整包。上传新版之前，请下载或保留自己仓库当前的版本。如果需要回退，恢复整套旧版文件，而不是混用旧 HTML 和新 assets。

### 开发构建的自动备份

已有 `dist` 时，再运行构建会先把旧产物移到源码目录的 `backups/build-时间-随机标识/dist`，再提交新产物。构建日志会给出准确位置。

校验或编译失败时旧产物保持原状；提交步骤失败会尝试自动恢复旧产物。若终端显示回滚失败，旧产物仍保留在日志所列备份目录，先复制它到另一个空目录确认可打开，再恢复发布目录。

突然断电可能留下 `.build.lock` 和构建临时目录。确认没有其他构建进程后再处理锁文件；不要在不确定时删除已有产物或备份。

## 常见问题

### 为什么上传后一直显示正在载入？

优先检查是否漏传 `assets` 文件夹，或 HTML 与 assets 来自不同版本。请上传完整站点包，不要只替换一个 HTML。

### 为什么没有真实登录或提交成功？

这是用于界面与需求评审的静态预览。客户、订单和金额都是示例；正式业务提交需要后续服务端接入。登录页不会收集真实密码。

### 为什么订单完成后仍显示缺发票？

按照既有需求，全部收货确认代表履约完成，开票可以跨月补齐，二者分开管理。

### 为什么商品没有显示 0 元？

价格尚未确认时显示“待报价”。未知价格不是零价格，核算方式也不会由展示页自行确定。

### 为什么名称选择没有自动恢复？

命名意见可能含自由文字，本版采用本次页面内记录、主动复制的方式。界面偏好与命名意见是两种不同资料。

### GitHub Pages 能直接保存真实业务吗？

当前包仅发布静态页面，页面和示例可被访问。后续使用真实业务资料前，需要服务端账号、公司级权限和受保护的文件存储。
